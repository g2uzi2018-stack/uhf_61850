# UHF 61850 局放监测管理机

本仓库用于 Nuvoton MA35D1-IoT（ARM64 / Ubuntu 22.04）局放监测管理机的研发。

当前阶段是设计基线，尚未开始产品代码实现。实现应先以模拟器完成协议和异常场景测试，再部署到实机验证串口、双网口和 IEC 61850 互操作。

## 当前结论

- 目标板足以运行本项目，也适合作为串口/网络/IEC 61850 集成测试机。
- 目标板不适合作为主要编译开发机；应在工作站或 CI 交叉编译 ARM64 发布包，再部署到板卡。
- `/data` 中旧 Python 网关只作为硬件映射和页面风格参考，不作为新项目代码基线。
- `frpc.service` 与 `4g_server` 不属于本项目，任何安装、测试和网络配置都不得停止、覆盖或接管它们。
- 产品允许按 GPLv3 兼容方式开源，使用 libIEC61850 1.6.2，无需购买商业许可证。
- IEC 61850 采用标准 `SPDC` 局放节点加 `GGIO` 五值映射；第一版只做浏览、读值和一个 URCB。
- Luna Max 按小功能增量实现，每次测试通过后提交并推送，避免大批量改动。
