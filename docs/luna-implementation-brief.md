# Luna Max 小步实现简报

这份文件是实际执行入口；详细边界和最终验收分别见 `requirements-baseline.md`、`architecture.md` 和 `implementation-plan.md`。

## 已确认，不再等待讨论

- 项目公开发布并采用 GPLv3 兼容许可证；使用 libIEC61850 1.6.2。
- 485-1 = `/dev/ttyS1`，485-4 = `/dev/ttyS4`；当前无接线，先用 PTY 模拟器开发。
- Modbus 线地址就是 10001–13615，不能减 1。
- IEC 61850 使用 `LLN0 + LPHD1 + SPDC1 + GGIO1`、一个静态数据集和一个 URCB。
- V1 有强放电和突变两类事件：-45/-50 dBm 触发/重新布防，或相邻有效峰值差 ≥10 dB；均保存前 2、当前、后 3 帧，同类 60 秒内合并。
- 不实现 BRCB、控制、GOOSE、SV、MMS 文件、动态数据集、数据库、容器或服务端绘图。

## 实现原则

1. 保持一个 C++17 产品守护进程；只有网络切换和设备重启进入小型 root helper。
2. 先做能在开发机测试的逻辑，再碰目标板；WP7 前不停止 `/data` 旧服务。
3. 一个提交只完成一个可描述的行为；测试与实现放在同一提交。
4. 每次提交前运行受影响测试；通过后立即 push 到 `main`，不 force-push。
5. Luna Max 自行决定普通类名、文件拆分和局部算法；只有违反需求、协议或安全边界时才需要停下来询问。

## 通用 IEC 61850 映射

| 数据引用 | 来源 | 含义 |
|---|---:|---|
| `PDMON/SPDC1.UhfPaDsch` | 10003 | 标准 UHF 局放峰值，MV/dBm |
| `PDMON/SPDC1.PaDschAlm` | V1 事件状态 | 标准局放告警，SPS |
| `PDMON/GGIO1.AnIn1` | 10001 | 平均值，MV/dBm |
| `PDMON/GGIO1.IntIn1` | 10002 | 放电频次，INS/次每秒 |
| `PDMON/GGIO1.AnIn2` | 10003 | 峰值，MV/dBm |
| `PDMON/GGIO1.AnIn3` | 10004 | 峰值相位，MV/° |
| `PDMON/GGIO1.AnIn4` | 10005 | 背景噪声，MV/mV |

所有值随同更新 `q` 和 `t`。`SPDC1` 提供标准语义，`GGIO1` 保留五个设备原始语义；少量重复是为了通用客户端兼容，不增加第二套采集数据。

## 事件语义

- 强放电：fresh/valid 峰值达到 -45 dBm；低于 -50 dBm 后重新布防。
- 突变：当前 fresh/valid 峰值与上一次 fresh/valid 峰值之差的绝对值达到 10 dB；无效/stale/not_refreshed 均跳过且不替换基线，启动后的第一份有效值只建基线。
- 一个事件包最多 6 帧：前 2、触发帧、后 3；后帧等待最多 30 秒。
- 60 秒内同类触发只累计计数和最大值，不增加帧、不延长窗口；同轮两类条件共用一个包并记录两个 reason。
