## 正式程序入口与当前边界

当前正式入口仍是 `src/main.cpp` 启动的 `uhf-gatewayd`。任何 `--v3` 启动先在进程入口复核设备绑定，因此 `--no-acquisition` 兼容分支也不能绕过；使用 `--v3 --v3-pd-device PATH --v3-current-device PATH --v3-temperature-device PATH` 时，`GatewayRuntime` 再独立复核，然后创建三个真实串口、`v3::AcquisitionScheduler`、v3 Modbus/TCP/RTU 分支、候选 IEC 三合一模型、v3 Web 快照和 `data/v3` 历史存储；不传 `--v3` 仍保持旧 PD1000 兼容路径。激活无效时在串口及所有 v3 服务创建前失败，不是只隐藏网页按钮。

审核者可在构建 `build/host/uhf-gatewayd` 后执行 `python3 tools/v3_host_sim.py`，使用终端打印的一次性账号访问 localhost 页面；此脚本只是把三路 PTY 接到同一正式入口，不是另一个演示后端。

实时总览已替换旧 PD1000/单通道/dBm 展示逻辑，形成由正式 schema 3 和 WebSocket 驱动的三通道局放、电流、温度、35 项计算值、质量和报警页面。下一阶段仍需完成目标盘压力、最终 IEC 点表/报告互操作和制造激活参数。生产所需电流/温度 profile、编码倍率、谱点单位、报警默认阈值、无效/过期最终约定和 IEC 点表仍需产品输入。

设置页和存储页通过正式 `/api/v1/snapshot/latest` 的 schema 识别运行模式。v3 只展示三路采集、换算、时效、12 点阈值和三合一历史字段；兼容配置仍保留在同一原子配置文件中但不会作为 v3 产品参数展示。v3 后端不会读取或导出旧 `data/events`，因为新需求没有确认 dBm 门限和事件包语义；是否需要新的 v3 事件策略仍是具体产品缺项。

## 已知暂定策略

- 新状态目录的总览标题默认改为“综合监测管理机 / 三合一监测设备”；已有配置文件中的用户自定义标题保持原值，不做覆盖式迁移。
- `CollectorOptions::max_retries` 表示首次尝试之外的重试次数，默认 3 且可热配置为 0–3；需求“重试 3 次”尚未明确总尝试次数。
- 局放 3 秒已按原文解释为同一完整通道两次读取的开始间隔，而不是同一通道 31 个分段请求的逐笔延时。`v3_pd_interval_ms` 下限固定为 3000；正式 PTY E2E 验证相邻轮次间隔及分段连续性，仍需实机确认设备准备时点。
- 电流/温度换算配置为 `v3_current_encoding` 和成对 multiplier/offset；编码只允许 `unconfigured`、`unsigned16`、`signed16`，倍率必须为正有限数。默认未配置时只记录下行通信，不发布看似正常的工程值。
- `uhf-gatewayd --v3` 的成对倍率命令行参数保留为主机模拟显式覆盖；缺一项或非正倍率在启动前拒绝。生产路径优先使用版本化原子配置，配置热切换会清空受影响值，电流切换还会重置 50 次窗口。
- 局放和上行 RTU 依据原文使用 115200/8N1；电流/温度 profile 默认 `unconfigured`，不会再默认为 115200。支持的 profile 为常见 termios 波特率加 `7/8 + N/E/O + 1/2`，例如 `9600/8E1`；配置变更明确返回需重启，主机 PTY 可用对应命令行参数覆盖。
- 12 个报警阈值通过 `v3_alarm_thresholds` 定长数组持久化；数值严格按 `>` 比较，`null` 在运行内表示 NaN 且报警有效位为 0。仓库默认全部为 `null`，测试阈值不是生产默认值。
- 激活测试使用仓库外临时测试密钥；仓库不包含默认密钥。生产应通过 `--v3-device-id-file`、`--v3-activation-key-file` 和首次激活时的 `--v3-activation-code-file` 提供外部文件，避免值出现在进程参数；内联选项仅为兼容和主机开发保留，同一个值同时指定内联与文件会在启动前拒绝。受保护文件必须为 root 或当前服务用户所有的普通非链接文件，不能组可写或对其他用户可读写，且只能包含一个不超过 256 字节的非空值。缺必要值时后端拒绝 v3 启动。
- 原文 §9.5 的常量时间比较已用 `CRYPTO_memcmp` 实现；§9.6 要求的未激活专用页面和成功后同进程开放功能仍未实现，当前首次激活依赖外部激活码文件，不能把后端门禁等同于完整激活交互。
- 三源时效默认局放 10 分钟、电流 5 秒、温度 5 秒，通过 `v3_pd/current/temperature_freshness_ms` 原子保存并热生效，Web 回显实际期限；1 秒至 24 小时范围是可逆安全边界。判定基于单调时钟，不受系统校时倒退影响。Web 将过期值置 `null`，Modbus 返回异常 04，IEC 保留最后有限值并标 `questionable/oldData`；默认值、范围和上行约定均未标记为用户确认。
- 历史格式当前写 v2（增加三源 UTC 和 stale 位），读取器兼容本轮较早提交产生的 v1；v1 没有源 UTC，读取为未设置而不伪造记录时间。
- 报文查看缓存固定为最多 256 条且载荷总计不超过 64 KiB，只记录三路下行串口实际成功收发的字节块；`read_some` 可能把一个 Modbus 应答分成多个条目。修改上限的入口为 `PacketTraceBuffer` 构造参数；没有报文落盘或导出接口。
- 快照失败时将对应值标为不可用；局放失败通道的原始字不会作为新鲜值发布。上述暂定上行选择仍待最终确认。
